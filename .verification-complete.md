## Critical Flow

```
┌─────────────────────────────────────────────────┐
│  PM opens chat (PM Chat Modal)                  │
└──────────────────┬──────────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────────┐
│  usePMChat (Hook)                               │
│  - getChatMessages(chatboxId)                   │
│  - Map each message                             │
│  - parseArtistRecommendations(message)          │
└──────────────────┬──────────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────────┐
│  Message object enriched with:                  │
│  - msg.artists = [artist objects]               │
│  - msg.text = "Artist recommendations"          │
│  - msg.stage = "recommending"                   │
└──────────────────┬──────────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────────┐
│  PMMessageItem (Component)                      │
│  - Check: hasArtists = msg.artists?.length > 0  │
│  - If true: Render ArtistRecommendations        │
│  - Display: CAROUSEL (NOT raw JSON)             │
└─────────────────────────────────────────────────┘
```
